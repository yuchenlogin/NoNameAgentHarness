## 原则速览

1. **上下文是资产，不是消耗品** —— 可版本化、可组合、可移植、可复利。
2. **规范即记忆** —— spec 开发内化：模型为自己的长期记忆维护规范，人只做批准。
3. **核心不可谈判，能力可以涌现** —— 沙箱/审批/账本必须物理保证；工作流交给模型与品味现场合成。
4. **界面是一张地图，不是控制面板** —— 少而准，作品是焦点。
