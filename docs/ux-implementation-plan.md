4. 用真实临时项目生成空白、日常、冲突与修正页面；浏览器验证桌面/窄屏、搜索、导航、证据与审批；跑适当回归和两仓测试。
5. 用 adversarial-review 技能通过 CLI 执行三视角审查，验证发现并修复，最后同步两端共享展示层、更新 README 与版本记录。

## 验收

- 默认不需要读 JSON、事件 ID 或内部字段即可知道现在有效的决定、下一步、待确认事项。
- 日常留证不混同长期记忆；旧决定只在历史和替代影响中出现，已批准当前状态来自原内核投影。
- 品味仍为软影响，模型提议的品味不自行采纳；审批与审计、冲突校验维持原契约。
- Codex 与 DSH 使用同一账本展示，静态导出也能阅读和筛选；没有模型调用或外部前端依赖。
- 实测反馈、自动化验证和限制据实记录，不宣称未经核验的持续运行或自动化能力。
