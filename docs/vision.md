# NoName Agent Harness · 愿景

> 写于 2026-08-16

## 一句话

NoName Agent Harness 是一个把「上下文」当作资产的 agent harness：
agent 与你的关系不是一次次会议话，而是一本持续复利的账本。

## 问题的起点

Transformer 的上下文窗口是有限的，但人的长期工作不是。
今天的 agent 工具把每一次会话当作一次性消耗品：上下文被填满、被截断、被遗忘；
你在不同的工具、不同的模型、不同的插件之间迁移，
但真正属于「你」的那部分——目标、判断、品味——每一次都要从头再来。

NoName 的答案不是「更长的上下文」，而是换一个问题：

**如果上下文不是消耗品，而是资产，会怎样？**

一个资产可以被：

- **版本化** —— 每次「压缩」都是一次提交，可以回看、可以回滚；
- **组合** —— 新会话 = 记忆 + 任务 + 注入的协作提示，拼接而成，从不原地修改；
- **移植** —— 上下文包与模型无关，换模型不换记忆、不换人格；
- **复利** —— 一个项目积累的决策与品味，成为下一个项目的起点。

## 四条原则

### 一、上下文是资产，不是消耗品

会话面临选择：继续当前上下文，或者带着「关键记忆」重生于新的上下文。
选择权属于一个显式的**路由**：由阶段边界、饱和程度、模型切换与你的指令共同决定。

关键记忆不是提示词的压缩包，而是一个**可版本化的上下文包**
（机制见 [architecture.md](architecture.md)）。它只保存决策与理由、状态与指针，
细节留在档案里可回溯——记忆负责「充分」，档案负责「准确」。

### 二、规范即记忆

openspec / speckit 式的规范开发之所以「外置」，是因为它们是一套
markdown 约定加命令行工具，需要人去填表。

在 NoName 里，**规范就是记忆层本身**：模型维护规范不是因为工具逼它，
而是因为它自己的长期记忆就依赖这份规范。工作区介绍、代码风格、决策记录
不再是你要填的表格，而是模型观察仓库后提出、由你罕见地批准或修改的「个人法典」。
你写的不是文档，你只是在批准自己项目的宪法。

### 三、核心不可谈判，能力可以涌现

插件系统的病：它为「已经知道自己要什么」的人服务，
却让探索者在一堆口径不一、品质参差、相互冲突的插件里迷失。

NoName 的赌注：模型正在越来越强，越来越多的「工作流」可以从
基础工具 + 明确意图 + 你的品味中**现场合成**，而不是预先安装。

但有一条边界不可谈判——**确定性保障**：沙箱、审批、账本、可验证的状态。
这些是「物理上不可能发生」，不是「模型决定不去做」。
因此内核很薄，但不可谈判；内核之外都是能力，既可以被插件结晶，
也可以被模型合成——而我们的方向，是让后者越来越便宜。

### 四、界面是一张地图，不是控制面板

少，不是简陋；少，是克制。界面让你一眼看见：正在发生什么（作品）、
agent 打算做什么（意图）、账本处于什么状态（记忆版本、当前模型、上下文年龄）。
选项按需出现，而不是永远占据屏幕。
敬仰 Anthropic 的设计哲学：让作品成为焦点，让工具退到背景。

## 品味层：一等公民

NoName 不只是你的工具，它携带你的**追求、生活态度与审美**——
你最近在听什么歌，你喜欢什么样的 vibe，你认为什么才算「足够好」。
品味不是花絮：在 AI 让「产出」变得廉价的时代，**品味与判断是最后的稀缺品**。
它以「例子与判断」的形式存在，而不是形容词；它属于上下文包的一部分，
因此换模型不换人格。

## 长期主义：为少数人做深，不为所有人做广

这个产品为谁而做？答案是：先为一个人——它的设计者本人——
然后是为同样相信「工具应该陪你走长期」的人。

它不优化传播，不追求通用。它是一笔复利：每一个项目都会让账本更厚、
让品味更清晰、让下一个项目起点更高。它做深，不做广。

### 关于这个时代的流量（一个观察）

2026 年夏天的两个现象：《中国人能飞》从一首歌变成全民情绪符号，
官媒下场背书（[观察者网](https://m.guancha.cn/culture/2026_08_06_826400)、
[机核](https://www.gcores.com/articles/217967)）；《牛来》靠「烂」出圈，
观众驱车 30 公里去「见证历史」，影院经理说比《奥德赛》好卖
（[上游新闻](https://www.cqcb.com/news/74/2026-08-16/6199682.html)、
[上观新闻](https://export.shobserver.com/toutiao/html/1160528.html)）。

它们火的不是「质量」，而是**可读性与在场感**：一个接住了集体的情绪，
一个让人花钱买的不是电影，而是「参与这场荒诞」的资格。
粗粝在 AI 内容泛滥的时代，反而成了「人类真实」的信号。

对这个产品的三条启发：

1. **稀缺已经迁移**。产出会越来越廉价，品味与判断是最后的稀缺品——
   所以品味层不是产品花絮，是最可辩护的差异化。
2. **不为传播优化**。为少数人做深，而不是为所有人做广；
   「通用」正是插件目录的病。
3. **可读性不是粗制滥造**。理念必须一句话就能被 get（「上下文是资产」），
   复杂藏在内部。这是合法的可读性：简介在表面，深度在里面。

## 不做的事

- 不做插件市场（插件可以是能力结晶，但不是默认入口）；
- 不急着做 demo（概念不清晰时，demo 只是浪费 token）；
- 不追求「所有人都会用」。

## 关于「伟大」

伟大不是影响力预言。伟大是把一件事做深，深到别人不得不认真对待。
如果有一天信心与品味被现实摧残，这个 harness 应该能提醒它的设计者：
你曾经把「工具」重新定义成「资产」——这件事本身值得被认真对待。

> 哪怕最后只有我一个人在用，我也愿意把它做出来。
