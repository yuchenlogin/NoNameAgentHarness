# 品味卡片

> 品味卡片把定期复核从「维护配置」变成一种具有情绪价值的回看体验，但卡片和生成图像都是品味证据的视图，不是事实本身。

## 1. 两条来源轨道

### Authored Taste · 自述品味

用户主动添加、编辑或明确声明的态度。例如：「在工作工具里，我更喜欢克制、信息密度高的设计」。它具有最高权威，可以设置全局或项目作用域。

### Adopted Taste · 采纳品味

模型在一次回答、作品或能力涌现中表现出令用户眼前一亮的倾向。用户点击「加入品味」后，系统提炼候选并保留原始回答引用。它必须明确标记为 `adopted`，不能伪装成用户原话。

观察到但未经确认的倾向只能是 `candidate`，不能进入活跃品味层。

## 2. 品味影响边界

品味可以影响：

- 候选方案排序；
- 风格、节奏、信息密度；
- 探索方向和模型配方推荐；
- 何时停手、什么算「足够好」；
- 用户愿意先看到哪类方案。

品味不可以：

- 改写事实或引用；
- 降低工具验证和测试标准；
- 绕过审批与安全规则；
- 覆盖用户当前任务要求；
- 让某个模型因为「更像你」就被判定为质量更高。

上下文中应把品味放在独立的 preference section，并明确标注为 soft influence。

## 3. 如何形成一张卡

1. 从已审核品味记录中按时间窗口和语义相似度形成候选簇；
2. 聚类器给出主题、共性、内部冲突和代表性证据；
3. 用户确认是否值得生成卡片；
4. 视觉模型根据结构化摘要生成漫画/插画；
5. 卡片发布前展示图像、文字摘要和原始证据；
6. 用户接受、修改、拆分、合并、暂停或退休。

embedding 只用于「哪些记录可能属于一组」的召回。最终分组和命名必须可解释、可修改。

## 4. 卡片内容

每张卡至少包含：

- 标题与一句态度；
- 来源：`authored / adopted / mixed`；
- 时间范围与最近确认时间；
- 适用作用域；
- 3–5 条代表性证据；
- 反例或张力（例如「喜欢简洁，但研究问题愿意接受复杂」）；
- 影响范围：表达、方案排序、模型推荐等；
- 视觉隐喻图；
- 状态：`candidate / active / paused / retired`。

卡片图像需要记录生成模型、提示、种子和版本，保证可以重建。用户随时可以只保留文字、重绘或关闭图像。

## 5. 复核体验：像抽卡，但不是赌博

可采用卡组和翻卡交互：

- 每周或每个阶段提供少量待复核卡；
- 正面先展示视觉隐喻和一句话，翻面查看证据、冲突与作用域；
- 操作为「保留、调整、暂停、退休、拆分」；
- 允许把旧卡与新卡并排比较；
- 形成季节/阶段卡册，展示人的变化而非单一终极画像。

卡片出现顺序由确定性审核优先级决定：长期未复核、证据冲突、近期频繁影响决策的卡优先。不要使用随机稀有度、连胜、抽奖概率或付费刺激。

## 6. 新旧品味如何共存

时间不是简单衰减权重。旧品味可能：

- 已过时，应退休；
- 只在旧项目或特定人生阶段有效；
- 与新品味形成真实张力；
- 仍是身份的一部分，但当前不活跃。

因此卡片支持时间区间、作用域和状态，而不是「新的一定覆盖旧的」。上下文组装时，根据任务、作用域和最近确认状态选择卡片；冲突时展示张力，不替用户假装统一。

## 7. 多模态风险

生成图像可能把抽象品味过度具体化，制造错误联想或刻板印象。产品必须做到：

- 图像始终标注为「视觉解释」；
- 一键查看文字与证据；
- 不用图像 embedding 反向证明用户品味；
- 不根据面部、种族、性别等敏感视觉元素推断人格；
- 用户可选择纯排版、摄影拼贴、抽象图形或关闭生成图。

最好的卡片不是最准确地「画出用户」，而是最容易帮助用户思考：这还是现在的我吗？
