Manifesto · 2026.08.16

NoName
Agent Harness

「上下文是资产，不是消耗品。」

agent 与你的关系不是一次次会议话，而是一本持续复利的账本。这里的每一个项目，都会让下一个项目的起点更高。

序

问题的起点

Transformer 的上下文窗口是有限的，但人的长期工作不是。今天的 agent 工具把每一次会话当作一次性消耗品：上下文被填满、被截断、被遗忘；你在不同工具、不同模型、不同插件之间迁移，但真正属于「你」的那部分——目标、判断、品味——每一次都要从头再来。

NoName 的答案不是「更长的上下文」，而是换一个问题：如果上下文不是消耗品，而是资产，会怎样？ 资产可以被版本化、被组合、被移植、被复利。下面的四条原则，是同一个主张的四个推论。

01

上下文是资产，不是消耗品

每次会话面临选择：继续当前上下文，或者带着「关键记忆」重生于新的上下文。选择权属于一个显式的路由——由阶段边界、饱和程度、模型切换与你的指令共同决定。

关键记忆不是提示词的压缩包，而是完整证据之上的可版本化索引：原始会话、工具结果与文件变化只增不改，每条长期记忆都能回到来源。上下文包只是为当前模型组装的可携带视图——压缩可以有损，溯源不能断。

02

规范即记忆

openspec / speckit 式的规范开发之所以「外置」，是因为它们是一套 markdown 约定加命令行工具，需要人去填表。在 NoName 里，规范就是记忆层本身：模型维护规范不是因为工具逼它，而是因为它自己的长期记忆就依赖这份规范。

工作区介绍、代码风格、决策记录不再是你要填的表格，而是模型观察仓库后提出、由你罕见地批准或修改的个人法典。你写的不是文档，你只是在批准自己项目的宪法。

03

核心不可谈判，能力可以涌现

插件系统的病：它为「已经知道自己要什么」的人服务，却让探索者在一堆口径不一、品质参差、相互冲突的插件里迷失。

NoName 的赌注：模型正在变强，越来越多的「工作流」可以从基础工具 + 明确意图 + 你的品味中现场合成，而不是预先安装。但有一条边界不可谈判——确定性保障：沙箱、审批、账本。这些是「物理上不可能发生」，不是「模型决定不去做」。

04

界面是一张地图，不是控制面板

少，不是简陋；少，是克制。界面让你一眼看见：正在发生什么（作品）、agent 打算做什么（意图）、账本处于什么状态（记忆版本、当前模型、上下文年龄）。选项按需出现，而不是永远占据屏幕。

敬仰 Anthropic 的设计哲学：让作品成为焦点，让工具退到背景。

核心

证据、记忆与上下文投影

法典 / Canon

项目目标、约束、非妥协项、决策与理由。变化慢，像宪法；模型提议，你批准。

任务态 / Task

当前目标、开放问题、阻塞、下一步。变化快，每次压缩重写。

指针 / Provenance

指向档案、文件与 git 版本，而不是复制内容。被压缩掉的细节，永远可回溯。

品味 / Taste

自述品味与采纳品味分开记录：态度、例子与判断可以影响排序和表达，但不改写事实，也不冒充生成质量。

任何能读这份包的模型，都能接管这份工作 —— 这就是热插拔的前提。

在 AI 让「产出」变得廉价的时代，品味与判断是最后的稀缺品。

品味层不是花絮：它决定 agent 如何措辞、给出什么选项、认为什么才算「足够好」。自述与采纳两条来源轨道分开审核；卡片和生成图像只是帮助你复核「这还是现在的我吗」的视觉解释，不是事实证据。

哪怕最后只有我一个人在用，我也愿意把它做出来。

—— 这个产品的设计者，于 2026 年夏天

长期

彩票，还是复利？

彩票 · 短期流量

期望值低，赢家可见。幸存者偏差让它看起来像策略，但热度是借来的，明天归零。玩它没有错——错的是玩着彩票，却期待复利的回报。

复利 · 长期主义

单日上限低，但地板高，且逐年累积。账本越来越厚，品味越来越清晰，下一个项目的起点越来越高。价值是自己的，不归零。

这个产品的赌注是复利：它不优化传播，不追求通用；它为少数人做深——先为一个人，再为同样相信「工具应该陪你走长期」的人。
